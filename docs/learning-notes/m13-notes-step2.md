# Milestone 13 学习笔记 — 交互式对话 (ReAct Agent + 前端)

## Step 2: 该阶段在项目中的作用

### 为什么需要 M13

M0-M12 完成了分析管线——输入 GitHub URL → 返回完整分析报告（JSON）。但实际使用时，用户不会满足于"读 JSON"：

1. **JSON 无法直接阅读**：1000+ 行的 JSON 对人类不友好
2. **无法追问**：看到架构分析说"查询引擎怎么实现的"——现有系统无法理解这个追问
3. **没有上下文**：POST /chat 是单轮 RAG 问答，每次请求独立，不知道之前聊过什么
4. **无法自主查资料**：对话只是基于 RAG 检索 + LLM 回答，不能主动调用工具

### M13 解决什么问题

| 问题 | M13 方案 |
|------|----------|
| 分析结果不可见 | 前端三栏布局：左侧展示完整分析报告（概述/技术栈/架构/学习路线/Mermaid 图） |
| 无法连续对话 | 多轮对话历史持久化，每轮携带完整上下文传给 LLM |
| 分析结果不能辅助对话 | 分析报告压缩为文本摘要注入系统提示词，AI 直接"知道"项目所有信息 |
| 对话无法查代码 | AI 自主调用 search_code 工具做 RAG 检索 |
| 对话无法查外部信息 | AI 自主调用 MCP 工具（GitHub Issues 等） |

### 输入 → 输出

```
输入:  浏览器 http://localhost:8000/chat
      → 粘贴 GitHub URL → 点 Analyze
      → 等待分析完成（左侧展示报告）
      → 输入对话消息

输出:  聊天框内多轮对话
      右侧面板展示 ReAct 推理步骤（调了什么工具、看到了什么）
```

### 与本阶段的关系

M13 是整个项目的"最后一公里"——把 M0-M12 的所有能力通过一个交互界面暴露给用户。
